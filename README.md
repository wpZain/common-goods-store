# Common Goods Store

A responsive sample e-commerce storefront built with Bootstrap 5, HTML, CSS, and vanilla JavaScript.

## Pages

- `index.html` - Product catalog, search, category filters, sorting, saved items, product quick views, and shopping bag.
- `about.html` - Brand story and design principles.
- `contact.html` - Contact form, contact details, and frequently asked questions.

## Features

- Responsive layouts for desktop and mobile.
- Light and dark themes, with the selected theme saved in the browser.
- Product gallery with alternate images and product details.
- Shopping bag with quantity controls and saved cart state.
- Client-side form validation and Bootstrap accordion components.

## Run locally

Open `index.html` in a browser. Bootstrap, Bootstrap Icons, web fonts, and product photography load from external CDNs, so an internet connection is required.

## Demo limitations

This is a front-end portfolio project. Checkout does not process payments, and the contact and newsletter forms do not send or store submissions. Product content and prices are sample data.
